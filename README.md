 
# ESTORA – Real Estate Website

**Find Your Perfect Space**

ESTORA is a modern, responsive real estate website built with React, Vite, and Tailwind CSS. It provides a premium property browsing experience where users can explore homes, apartments, rental properties, and commercial spaces.

## Features

- **Modern Homepage** – Premium hero section, featured properties, and property categories.
- **Buy Properties** – Browse properties available for purchase.
- **Rent Properties** – Explore residential and commercial rental listings.
- **Property Details** – View property images, prices, descriptions, amenities, and specifications.
- **Wishlist** – Save and remove favourite properties.
- **Sell Property** – Property submission and enquiry interface.
- **About Us** – Information about ESTORA.
- **Contact Us** – Contact and enquiry section.
- **Advanced Animations** – Smooth transitions and interactive hover effects using Framer Motion.
- **Intro Animation** – Cinematic ESTORA brand introduction before entering the website.
- **Responsive Design** – Optimized for desktop, tablet, and mobile devices.
- **Navigation** – React Router-based page navigation.
- **Local Storage** – Wishlist items are saved in the browser.

## Technologies Used

- React.js
- Vite
- Tailwind CSS
- JavaScript (ES6+)
- React Router DOM
- Framer Motion
- React Icons
- HTML5
- CSS3
